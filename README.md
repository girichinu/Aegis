# AEGIS - Tourist Safety & Emergency Response Platform
### 🚀 Live Demo
Check out the live application here: [Aegis Live URL] (https://aegis-tau-sand.vercel.app/)

A practical full-stack platform built for tourist safety, featuring digital identity verification, real-time safety mapping, risk alerts, incident reporting, an AI safety advisor, and an authority monitoring dashboard.

## Tech Stack
- **Frontend & Routing**: Next.js (App Router), React, Tailwind CSS
- **Icons**: Lucide-React
- **Database & Backend**: Supabase (Incident storage and retrieval)

## Key Features
- **Digital Tourist ID**: Quick identification and verification card with a digital identifier.
- **Location-Based Safety & Risk Alerts**: Live safety mapping alongside real-time area risk warnings.
- **Incident Reporting**: Form-based reporting allowing tourists to log emergencies or issues.
- **AI Safety Advisor**: Intelligent assistant providing contextual safety guidelines.
- **Safety Resources**: Quick-reference direct helplines and emergency numbers.
- **Authority Dashboard**: Administrative interface (`/authority`) for tracking and managing alerts.
